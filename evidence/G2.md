## Implementation and source identity

The receiver is a separate Python process and SQLite database under `receiver/`, listening only on `[::1]:8767`. Its Windows runtime is outside the checkout at `C:\ACLAIS-Lab\state\receiver`. It stores only SHA-256 digests of run-bound ingest credentials, keeps the distinct random admin credential in the owner-protected runtime, persists receipt intent and metadata separately from UUID-named raw payload files, and reconciles publication state before serving. Admin inspection returns metadata only. The service cannot call or write ACLAIS APIs; the ACLAIS adapter performs health and receipt GETs only.
