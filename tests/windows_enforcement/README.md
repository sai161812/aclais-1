# Windows enforcement checks

This lane is reserved for automated checks that use real Windows identities, NTFS access controls, Windows Credential Manager, and Job Objects. A2's private demonstration-machine probe ran against the actual `AclaisWorker` identity; its result is in [`../../evidence/A2.md`](../../evidence/A2.md). No Windows enforcement CI job or A3 Job Object implementation exists yet. The automated Windows lane is `NOT_RUN`; A2 demonstration-machine evidence does not imply later launcher/job enforcement. Portable CI does not prove Windows enforcement. Do not replace a required Windows check with a mock or mark an absent/skipped test as passed.
